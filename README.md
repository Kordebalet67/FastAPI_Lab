# FastAPI_Lab

# Общее задание
Сделать небольшое веб-приложение в виде лэндинга / одностраничного сайта на FastAPI. Организовать разграничение доступа по трем категориям: 
- неавторизованный - ничего не может,
- читатель - может смотреть содержимое главной страницы и свой профиль, но не может ничего менять / создавать,
- админ - может всё.
Данные пользователей (логин, зашифрованный пароль, путь к аватару) хранить в файле users.csv.
Любые иные данные, касающиеся приложения хранить в файле data.csv.
Организовать логирование действий всех пользователей - куда переходил, какие действия на страницах выполнял. Логи хранить в файле logs.
Реализовать сессии для каждого пользователя с таймаутом 5 минут. Использовать HTTPS для организации работы приложения.
 

Обязательные страницы:
- Логин / регистрация (в одной странице или в разных)
- Главная страница
- Страница изменения / добавления содержимого главной страницы
- Страница личного профиля
- 404
